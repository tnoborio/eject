# EJECT ⏏

[English](README.md)

> 真面目な技術。ほとんどない目的。

EJECTは、ほとんど何の役にも立たないIoTソーシャルネットワークです。
友達が、あなたのコンピューターにつながったCDトレイを開けられます。

アカウント、権限管理、リアルタイム通信、ネイティブのデスクトップアプリ、
OSのデバイスAPIを使って実現するのは、たったひとつの小さな物理現象です。
どこかで、トレイが開きます。

## アイデア

多くのコネクテッドプロダクトは、利便性、自動化、生産性によって存在意義を
説明します。EJECTはそうしません。遠くにいる誰かが、自分のいる物理空間へ
一瞬だけ触れたように感じられる。その奇妙さ自体が価値です。

EJECTは遠隔端末管理ではありません。1ビットのフィジカルSNSです。

## 中心体験

1. アカウントを作ります。
2. EJECTデスクトップアプリをインストールします。
3. 対応する光学ドライブを登録します。
4. 友達を招待します。
5. その友達が自分をejectすることを、明示的に許可します。
6. 友達が **EJECT** を押します。
7. トレイが開き、誰がejectしたのかデスクトップに表示されます。
8. 相手をejectし返すことができます。

```text
Kazがあなたをejectしました。

[ EJECTし返す ]
```

主役となるインターフェースは画面ではなく、トレイです。

## プラットフォームについて

Windowsにはリムーバブルメディアをejectするデバイス制御手段があるため、
トレイ式光学ドライブを第一の対象とします。

macOSにもディスクをejectするAPIはありますが、現行Macでは外付け光学ドライブが
中心で、その多くはスロットローディング式です。そのためmacOS対応は設計上
考慮しますが、実機で物理的なトレイ動作を検証できるまではexperimentalとします。

## スコープ

EJECTは、タイムライン、投稿、いいね、チャット、カメラ、マイク、任意の遠隔
コマンド、予約実行、Bot、汎用IoTプラグイン機構から始めません。新機能は、
このアイデアの小ささを守れる場合にのみ採用します。
