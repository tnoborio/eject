# EJECT logo

[日本語](README.ja.md)

The adopted mark is **One Bit**, selected from the
[logo concept study](../logo-concepts/README.md) (concept S1). A single bit
leaves its slot in a bit field and is ejected upward: one action, one physical
result, in the smallest unit of data.

All files are self-contained SVG lockups on a dark plate, so they remain
legible in both GitHub light and dark themes. No tagline is embedded, allowing
the surrounding document to remain localized.

## Files

| File | Use |
| --- | --- |
| `logo.svg` | Primary lockup (mark + wordmark), 960×320 |
| `logo-mono.svg` | One-color lockup for contexts where the accent color is unavailable |
| `mark.svg` | Square mark only, 256×256 — avatars, favicons, app icons |
| `mark-mono.svg` | One-color square mark |

In the one-color variants the vacated slot is drawn as a gap in the row rather
than a dimmed outline, so the mark still reads in a single color.

## Colors

| Role | Value |
| --- | --- |
| Plate | `#111311` |
| Ink | `#F2F0E8` |
| Ejected bit | `#D96B43` |
| Vacated slot | `#3A3E39` |

The mark remains legible at 32 px.
