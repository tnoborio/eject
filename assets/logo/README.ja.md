# EJECT ロゴ

[English](README.md)

採用したマークは、[ロゴ検討](../logo-concepts/README.ja.md)(案S1)から選ばれた
**One Bit** です。ビット列の中の一つのビットがスロットを離れて上へ排出される
——「一つの操作が、一つの物理現象を起こす」を、データの最小単位で表しています。

すべてダークな下地を含む独立したSVGロックアップであり、GitHubのライト／
ダーク両テーマで読めます。周囲の文書を翻訳できるよう、タグラインは
埋め込んでいません。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `logo.svg` | 基本ロックアップ(マーク+ワードマーク)、960×320 |
| `logo-mono.svg` | アクセント色が使えない場面向けの単色ロックアップ |
| `mark.svg` | 正方形のマーク単体、256×256 — アバター、ファビコン、アプリアイコン |
| `mark-mono.svg` | 単色の正方形マーク |

単色版では、空いたスロットを薄い枠線ではなく列の空隙として描くことで、
1色でも成立するようにしています。

## 色

| 役割 | 値 |
| --- | --- |
| 下地 | `#111311` |
| インク | `#F2F0E8` |
| 排出されたビット | `#D96B43` |
| 空いたスロット | `#3A3E39` |

マークは32pxでも判読できます。
