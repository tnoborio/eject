# Brand and Language

[日本語](BRAND.ja.md)

## Identity

- **Display name:** EJECT
- **Repository and technical identifier:** `eject`
- **Primary symbol:** ⏏
- **Intended URL:** `eject.sasra.io`
- **Studio signature:** EJECT by sasra

The name is a command, an existing physical action, and a word that becomes
slightly alarming when applied to a person. The harmlessness of the actual event
creates the contrast.

Do not rename the product to explain the joke. The directness of EJECT is part
of the concept.

## Primary description

> EJECT is an IoT social network with almost no purpose. It lets your friends
> eject the CD tray connected to your computer.

## Primary line

> Serious technology. Almost no purpose.

## Product promise

> EJECT does one thing, physically, with consent.

## Voice

The voice is:

- brief;
- factual;
- calm;
- technically precise;
- deadpan rather than comedic;
- human without being cute.

Prefer:

```text
Kaz ejected you.
Tray opened.
Device offline.
Eject back.
```

Avoid explanatory humor, exclamation marks, exaggerated cyberpunk language,
gamified pressure, or claims that EJECT is useful.

## Visual direction

The ⏏ symbol should remain recognizable and functional, not merely decorative.
The interface should feel deliberate and trustworthy enough to authorize a
physical action. The absurdity comes from the purpose, not from visual clutter.

No final colors, typography, or logo lockup are decided in this document.

## Vocabulary

- Use **eject** for the social action.
- Use **tray opened** only for a confirmed physical outcome.
- Use **sent** or **delivered** for intermediate network states.
- Use **person** or **friend**, not operator or controller.
- Use **device** for a computer running the agent.
- Use **drive** for the locally approved optical drive.
- Use **EJECT BACK** for the reciprocal action.

The product name remains `EJECT` in every locale. The surrounding language is
localized.
