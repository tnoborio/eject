# セキュリティとプライバシー

[English](SECURITY.md)

EJECTは、遠隔にいる人が別の人のコンピューター上で物理操作を起こせるようにします。
操作は小さくても、信頼境界は現実に存在します。セキュリティは実装詳細ではなく、
プロダクトコンセプトの一部です。

## セキュリティ不変条件

1. 受信者の有効な許可なしに、別の人をejectできない。
2. サーバー命令から任意のローカルデバイスパスを選べない。
3. アプリは任意のコード、コマンド、スクリプト、プラグインを実行できない。
4. 各命令は一台の登録端末に結びつき、短時間で失効し、一度しか受理できない。
5. 人または端末の取り消しは、アプリ更新を待たずに有効になる。
6. アプリは外向き接続だけを行い、遠隔操作ポートを公開しない。
7. ディスク内容を読まず、挿入メディアを推測しない。
8. 通信成功を、確認済みの物理成功として表示しない。

## 脅威モデル

初期設計では次を考慮します。

- 悪意がある、または侵害された友達アカウント。
- 嫌がらせや機器への負荷を目的とした連続命令。
- 命令の再送、遅延、改変、誤配信。
- デスクトップアプリ認証情報の窃取。
- Webセッションの侵害。
- ローカル実行範囲を広げようとする悪意あるサーバーペイロード。
- 再接続後に変化するドライブ識別子。
- 関係、在席、端末動作を漏らすログ。
- 改変アプリを配布する更新経路。
- トレイが物体に当たる、または連続動作する物理リスク。

## 認可

権限は方向を持ち、明示的に与えます。「AliceとBobが友達」であることは、Bobが
Aliceをejectできることを意味しません。Aliceが許可、一時停止、制限、取り消しを
管理します。

命令発行時に少なくとも次を評価します。

- 認証済みの実行者。
- 必要な場合の有効な関係。
- 受信者による有効な許可。
- 受信者の一時停止とおやすみ時間。
- 送受信者の回数制限。
- 対象端末の登録と適格性。
- 不正利用やアカウント制限。

アプリ側でも命令の対象端末、完全性、有効期限、命令IDを検証します。サーバー認可は
ローカル検証の代わりにはなりません。

## 能力の封じ込め

命令プロトコルは閉じた種類だけを持ちます。初期の物理命令は
`OPTICAL_DRIVE_EJECT`だけです。

命令に次を含めません。

- シェル文字列。
- 実行ファイルパス。
- DLL・ライブラリ名。
- 汎用IO制御コード。
- 任意のデバイスパス。
- 実行可能ペイロードのURL。
- コードとして解釈されるスクリプトやシリアライズオブジェクト。

許可済みドライブとの結合は受信者のコンピューター上で作成し、送信者には選ばせません。

## 不正利用と物理安全

- 受理したeject後に、受信者が管理するクールダウンを適用する。
- 第二層としてサーバー側の短時間・一日単位制限を設ける。
- ローカルでのワンクリック一時停止と即時取り消しを提供する。
- 初期版ではトレイを遠隔で閉じない。
- セットアップ時にトレイ前方の物理空間を空けるよう案内する。
- ローカル試行は一度で止め、受信者が操作しない限り再試行しない。
- 機械的な連続動作より失敗を選ぶ。
- 初期版では匿名の公開アクセスを無効にする。

## 認証情報と通信

- 通信中は現代的な認証付き暗号を使用する。
- 端末ごとに取り消し可能な認証情報または鍵ペアを与える。
- OSの保護ストレージが利用できる場合は更新用認証情報をそこへ保存する。
- URL、ログ、分析、通知文に端末認証情報を含めない。
- サーバー秘密情報をローテーションし、端末セッションを即時無効化できるようにする。
- 一般公開前に、配布アプリと更新へ署名し検証する。

具体的な暗号方式は実装時に選定し、独立したレビューを行います。この文書では必要な
性質を定義します。

## プライバシーとデータ最小化

EJECTは次を必要としません。

- カメラ・マイクへのアクセス。
- スクリーンショット。
- ディスク名、ファイル名、内容。
- 継続的で細かな在席履歴。
- コンピューターハードウェアの詳細一覧。
- 部屋、位置、周辺端末の情報。
- 広告プロファイル。

最近の操作表示、障害診断、不正利用制御、セキュリティ調査に必要な期間だけイベントを
保存します。非公開アルファ前に削除方法と保存期間を定義します。

## ログ

範囲の限定された識別子と理由コードを使います。認証情報を除去し、生のペイロードを
ログへ残しません。ユーザー向け履歴とセキュリティ監査データを分け、両方の運用アクセス
を制限します。

## 一般公開前に必要なインシデント操作

- 一台の端末を無効化する。
- 一つのアカウントの全セッションを無効化する。
- 全eject配信を一括停止する。
- 一人の不正利用者をブロックする。
- 未実行命令を無効化する。
- 署名・サービス認証情報をローテーションする。
- 確実性を誇張せず、要求・配信・実行のどこまで起きたかを通知する。

## 報告窓口

一般公開アルファ前に、セキュリティ連絡先と責任ある開示手順を追加します。監視され、
対応可能な窓口を用意するまでは脆弱性報告を募集しません。
